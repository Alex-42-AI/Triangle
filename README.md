# Triangle
Takes as input what the user knows about a triangle when it comes to its sides, angles and heights and returns everything that can possibly be known about it, i.e. values in the triangle, as well as coordinates of its points, the triangle center point, the outer circle center point and the inner circle center point. When the solver decides it has enough information to calculate everything, it ignores values with lower priority even if they're given, regardless of whether they're consistent with the calculations or not. The solver's priorities are: sides, then angles, then heights. Within a given metric, the priority is A, then B, then C.
